Проєкт

Цей проєкт був створений як кваліфікаційна робота у межах спеціальності Комп'ютерна інженерія.

Опис

Проєкт представляє собою візуалізацію Марковського процесу (МП), який класифікується за двома критеріями: стаціонарність та дискретність.

  • Марковський процес - такий, у якому ймовірність системи перейти в інший стан залежить лише від поточного стану і не залежить від історії переходів.
  • Стаціонарний МП - такий, у якому ймовірність переходу є постійною з часом, описується константою. В іншому випадку вона описується функцією від часу.
  • Дискретний МП - такий, що можна розділити на конкретні кроки, синоніми - "непостійний", "не безперервний", антоніми відповідно - "не дискретний", "постійни", "безперервний".

Детальніше за посиланнями:

  • Ching, Wai-Ki, and Michael K. Ng. Markov Chains: Models, Algorithms and Applications. Springer, 2006. - 211 р.

Можливості програми

Програма дозволяє досліджувати Марковський процес на визначеному проміжку часу із заданою точністю. Завдяки природі МП, можливе дослідження на нескінченному проміжку часу, і точність у цьому випадку не є критичною.

Дослідження можуть бути візуалізовані у таких форматах:

  • Граф
  • Графік
  • Таблиця

    • З можливістю збереження результатів

Деталі роботи з програмою

При запуску програму перше що пропонується користувачеві - змінити мову у меню вгорі

В залежності від досліджуваного процесу оберіть його параметри з випадаючих списків: стаціонарний/нестаціонарний, постійний/непостійний. При зміні на постійний режим імовірності заміняються інтенсивностями і розблокується головна діагональ. При виборі нестаціонарного режиму при виборі кожної клітини з'являтиметься поле для введення функції, але можливість вводити константи зберігаються. Пропонується вставляти функції з буфера обміну, щоб унеможливити помилки.

Матриця збільшується при збільшенні кількості станів. Кількість переходів змінюється автоматично в ході заповнення матриці.

Параметри Час дослідження і "Кількість кроків" відповідають за точність проведених досліджень. Змінюйте їх так, щоб у таблиці "Результати" останні 2-3 рядка повністю збігались, а на вкладці "Графіки" всі графіки були гладкі та прямували до своїх асимптот (зазвичай це горизонтальна лінія).

Використовуючи цифри, стрілки на клавіатурі, клавішу Enter можете заповнити матрицю. Управління є інтуїтивним, достатньо лише клавіатури. Різниці між комою і крапкою немає. Помилки виправлятимуться автоамтично.

В програмі відсутні кнопки "Вирішити" чи "Зробити", тому просто перемикайтесь між вкладками, рівняння вирішуються автоматично.

На вкладці "Граф" можна перевірити, чи вийшов процес на схожий до того, що ви досліджуєте. Ця вкладка є суто візуалізацією.

На вкладці "Результати" наводяться результати дослідження у вигляді таблиці.

На вкладці "Графіки" наводяться результати дослідження у вигляді графіків. Ця вкладка є суто візуалізацією.

Вкладки 2, 3, 4 можна зберегти у відповідних форматах за допомогою меню "Файл".

Project

This project was created as a qualification work within the specialty Computer Engineering.

Description

The project represents a visualization of a Markov process (MP), which is classified based on two criteria: stationarity and discreteness.

  • Markov process - a process where the probability of transition to another state depends only on the current state.
  • Stationary MP - a process where the transition probability remains constant over time.
  • Discrete MP - can be divided into specific steps.

More details at:

  • Ching, Wai-Ki, and Michael K. Ng. Markov Chains: Models, Algorithms and Applications. Springer, 2006. - 211 р.

Program Capabilities

The program allows studying the Markov process over a specified time interval with a given accuracy. Due to the nature of the Markov process, it can be analyzed over an infinite time interval, and accuracy in this case is not critical.

The research can be visualized in the following formats:

  • Graph
  • Graphics
  • Table

    • With the ability to save results

Program Usage Details

When the program starts, the first thing offered to the user is to change the language in the top menu.

Depending on the studied process, select its parameters from the dropdown lists: stationary/non-stationary, petmanent/non-permanent. When switching to petmanent mode, probabilities are replaced with intensities, and the main diagonal is unlocked. When selecting the non-stationary mode, a field for entering a function will appear for each selected cell, but the ability to enter constants remains. It is recommended to paste functions from the clipboard to avoid mistakes.

The matrix expands as the number of states increases. The number of transitions changes automatically as the matrix is filled.

The parameters Research Time and "Number of Steps" determine the accuracy of the conducted studies. Adjust them so that in the "Results" table, the last 2-3 rows completely match, and in the "Graphics" tab, all graphs are smooth and tend to their asymptotes (usually a horizontal line).

You can fill in the matrix using numbers, arrow keys, and the Enter key. The controls are intuitive and require only a keyboard. There is no difference between a comma and a dot. Mistakes will be corrected automatically.

The program does not have "Solve" or "Execute" buttons, so just switch between tabs; the equations are solved automatically.

In the "Graph" tab, you can check if the process resembles the one you are studying. This tab is purely for visualization.

In the "Results" tab, research results are presented in a table format.

In the "Graphics" tab, research results are presented as graphs. This tab is purely for visualization.

Tabs 2, 3, and 4 can be saved in the corresponding formats using the "File" menu.

More information about Markov process research can be found in the "Computer Systems" course.
